# Smart Badminton Studio 完整使用教程

Studio 有两个版本：浏览器快速版负责免安装剪片，原生精准版提供完整 Hybrid、球路、姿态与比分。本教程以下内容主要对应原生精准版。

浏览器快速版只需选择视频、快速分析、拖动边界并输出 MP4；视频不会上传。

可在顶部语言选择器切换中文和英文。首次打开会按浏览器偏好自动选择支持的语言，手动选择会被记住。日夜模式独立于语言设置。

## 1. 先理解四种不同的数据

1. **源视频**：手机拍摄的原始高清文件。最终成片永远从它读取。
2. **代理视频**：Studio 自动生成的 720p 浏览预览，用于降低拖动时间轴时的读盘压力。
3. **剪辑时间表**：每一分的开始和结束时间。你在时间轴上的修改只改变它。
4. **视觉分析**：YOLO 人物姿态、羽球候选与轨迹缓存。它们帮助检查，但不会自动改写手工确认过的时间表。

## 2. 推荐的完整工作顺序

> 选择文件夹 → 打开视频 → 校准场地 → 自动剪片 → 时间轴校对 → 保存时间表 → 输出成片

YOLO 姿态和羽球轨迹是可选步骤。它们效果不好时可以完全不打开，不影响手工剪片。

## 3. 选择输入视频与输出位置

在页面最上方的项目栏：

1. 点击“输入视频文件夹”右边的“选择”。
2. 进入保存比赛源视频的目录，点击“选择当前文件夹”。
3. 在“比赛视频”下拉框选择一条视频，然后点击“打开”。
4. 设置“成片输出文件夹”和 `.mp4` 文件名，点击“应用”。

Studio 会递归寻找视频，但会忽略 `Proxy`、`Edited`、`Analysis` 等派生目录，避免把成片再次当作源视频。

## 4. 第一次使用一个新机位：场地校准

展开“02 场地与轨迹工具”，点击“框选球场”。在画面中选择区域并点击添加顶点，圆点可以拖动微调。

必须完成五个区域：

- **有效比赛场地**：只包住当前比赛真正活动的场地。
- **近场脚点区域**：近场球员双脚可能出现的位置，不是人物全身框。
- **远场脚点区域**：远场球员双脚可能出现的位置。
- **球网区域**：覆盖球网附近的狭长区域。
- **羽球飞行空域**：宽松覆盖本场羽球可能飞过的位置。

推荐先画“有效比赛场地”，再点“从有效场地生成辅助区”，最后按实际画面微调。隔壁场、灯光反射或固定白点可放入“背景排除区”或“静态误检区”。

四个橙色场地角点和青色透视轴是可选辅助信息。单目视频无法可靠恢复羽球三维高度，所以 Studio 不会把二维投影冒充准确落点。

### 校准保存后怎么重新预测

1. 点击“保存校准”。
2. 如果要重新生成剪辑片段，点击“重新跑剪片预测”。确认后，当前时间表会先生成 `.bak`，然后模型结果替换 Studio 时间轴。
3. 如果只想更新播放器上的人物姿态和羽球轨迹，点击“按新校准重跑整段视觉”。它不会修改剪辑时间表。

不要在顶点仍显示“未保存”时运行分析；两个重跑按钮会保持禁用。

## 5. 自动剪片

展开“01 自动剪片”：

- **前留**：模型检测到 rally 前保留的秒数。
- **后留**：模型认为 rally 结束后保留的秒数。
- **过滤送球**：尝试排除把球轻轻送给下一位发球者的动作。

点击“自动分析当前视频”会重新预测当前视频的时间表。已有时间表时，确认框会明确提示替换和备份。点击“批量分析新比赛”只处理还没有时间表或完成标记的视频。

自动结果是初稿。最后一拍未击中、轻放、下网、高远球落地和出界仍应由人检查。

## 6. 播放器和时间轴剪辑

- 点击时间轴空白处：精确移动播放头。
- 点击片段：选择该 rally。
- 拖动片段左/右边缘：调整开始或结束。
- Inspector 中的“开始/结束 −1 帧、+1 帧”：精细修正。
- “在播放头分割”：把当前片段切成两段。
- “新增片段”：在播放头附近的空白区创建片段。
- “删除片段”：从时间表移除，之后可撤销。
- “成片预览”：按当前时间表连续播放，自动跳过删除的空白时间。

快捷键：

- `Space`：播放/暂停
- `←` / `→`：逐帧后退/前进
- `[`：把播放头设为当前片段开始
- `]`：把播放头设为当前片段结束

修改完成后点击顶部“保存时间表”。没有保存前不要输出最终成片。

在 Inspector 的比分卡点击“计算比分”。Studio 会先保存未提交的时间轴，再按最终片段计算整场比分；修改时间轴后需要重新计算。未确认的分保持未知，可用比分卡按钮人工修正。

## 7. 整段视觉分析和播放器叠加

展开“02 场地与轨迹工具”，点击“分析整段视觉（姿态＋羽球）”。这个后台任务会：

- 生成整段视频的 YOLO 人物框、骨架与手腕轨迹覆盖视频。
- 检测整段羽球候选并连接轨迹。
- 把结果缓存在当前项目的 `Analysis` 目录。
- 保持剪辑时间表不变。

“羽球检测”可选择：

- **Hybrid**：融合 YOLO 与 TrackNet，推荐。
- **TrackNet**：使用连续画面轨迹模型。
- **YOLO**：只使用逐帧候选框。

完成后，播放器上方的两个开关才会启用：

- **YOLO 姿态**：显示/隐藏全片人物姿态覆盖层。
- **羽球轨迹**：显示/隐藏与源时间同步的青色短尾迹。

这两个开关只负责查看结果，不会在点击时偷偷启动训练。模型不准时，重复运行同一模型不会自动变准。

### 后台任务和进度

启动自动剪片、整段视觉或羽球轨迹后，页面顶部的“后台任务”会常驻显示当前百分比。点击它可以查看当前视频、执行阶段、已运行时间和错误原因。

任务运行在本机的 Studio 后端，不依赖当前工具面板：刷新页面、关闭教程、折叠设置或切换到其他浏览器标签都不会取消，重新打开页面会自动接回任务状态。必须保持 `127.0.0.1:8765` 服务运行；若整个服务被关闭，任务会记录为中断，重新启动后需要再次点击分析，但已生成的代理、原始检测等缓存会继续复用。

## 8. 羽球轨迹修正不是模型训练

“查看／修正羽球轨迹”工具中的单点有两个用途：

- **补一个羽球点**：在当前帧加入人工观测，帮助轨迹跨过一次漏检。
- **排除附近误检**：删除当前时刻附近被误认为羽球的目标。

保存后重新运行整段视觉分析即可更新轨迹。

点标注可导出为 TrackNet 的逐帧坐标标签；YOLO 训练仍需要矩形框。

## 9. 动作统计和比分

Inspector 中的击球候选、节奏、杀球候选和精彩指数属于娱乐分析，可能不准确。它们不会改变剪辑时间表。

比分只有在终局轨迹或下一分正式发球方提供足够证据时才自动确认。点击得分方即可校正；需要作为训练依据时，展开“标注依据”补充本分发球、最后击球、终局、落点或送球。重新计算会用人工结果校准本资料夹的终局规则，比分修正不会改变剪辑时间表。

多模态标注需要设置 `SMART_BADMINTON_VLM_API_KEY` 和 `SMART_BADMINTON_VLM_MODEL`；兼容服务另设 `SMART_BADMINTON_VLM_ENDPOINT`。重启 Studio 后点击“标注未知比分”，再采用或忽略建议。

二维“假落点球场”已经从界面移除。单机位没有可靠三维高度时，不展示看似精确但未经验证的落点图。

## 10. 输出 1080p60 成片

1. 确认时间表已经保存。
2. 确认顶部显示正确的输出目录和文件名。
3. 点击“输出成片”。
4. Studio 从高清源视频读取片段并输出，不会放大代理视频。

已有同名成片时，确认框会说明将覆盖文件。编码器会实际探测 NVENC、QSV、VideoToolbox 或软件 H.264，并在运行失败时尝试可用回退。

## 11. 文件放在哪里

每个项目通常包含：

- `Analysis/`：模型特征、羽球轨迹、姿态覆盖层和 Studio 工作数据。
- `Proxy/`：浏览器预览视频。
- `Edited/`：最终成片。
- `Calibration/`：该机位的场地配置和备份。
- `Shuttle_Annotations/`：当前视频的人工羽球补点与排除记录。

不要手工删除源视频。`Analysis` 和 `Proxy` 是可以重新生成的派生数据；时间表和人工标注删除前应保留备份。

## 12. 常见状态解释

- **未校准**：五个必需区域没有全部保存。
- **当前视频未分析**：模型已配置，但还没有真实输出文件。
- **需更新/已过期**：校准、模型、原始检测或人工标注比结果新，需要重新分析。
- **按钮禁用**：通常是依赖未配置、校准未保存、另一个后台任务正在运行或 FFmpeg 不可用。把鼠标停在按钮上可查看原因。
- **轨迹很多但明显错误**：检测模型不适合当前角度。使用排除点只能修当前视频；长期解决方案是矩形框训练数据和重新训练检测器。
- **姿态识别远场人物错误**：当前小型通用姿态模型对远距离、遮挡和运动模糊能力有限。可以关闭叠加，剪片功能仍可使用。

## 最短检查清单

- [ ] 输入和输出文件夹正确
- [ ] 场地五个区域已保存
- [ ] 自动剪片结果已逐球检查
- [ ] 每分结束包含落地、下网或出界后的必要画面
- [ ] 相邻片段没有重叠造成重复动作
- [ ] 时间表已保存
- [ ] 输出文件名和目录正确
- [ ] 最终成片已完整播放抽查
