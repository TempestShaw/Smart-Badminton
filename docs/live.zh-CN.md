# 实时分析

把摄像头对准球场开打，同一 Wi-Fi 下的手机、平板或电脑都能实时看到回合计时、拍数、球员跑动和站位。分析由一台电脑完成，观看只需要浏览器。

实时分析是打球时的即时反馈。要得到可编辑的精彩集锦，请同时录像，结束后在 Studio 里跑完整的离线分析。离线流程处理每一帧，结合比赛声音和整段视频的上下文，结果仍以它为准。

## 开始实时分析

先按主 README 安装视觉依赖和模型，然后在负责分析的电脑上启动实时服务：

```bash
smart-badminton live --library /path/to/matches --host 0.0.0.0
```

终端会打印访问地址，例如 `http://192.168.1.20:8765`。在电脑上打开，或者在同一网络的手机上打开，就能在场边观看。正常的 Studio 会话里，顶栏的 **实时分析** 按钮会打开同一个页面；要让其他设备访问 Studio，需要用 `--host 0.0.0.0` 启动。

选择画面来源：

| 来源 | 适用场景 | 填写内容 |
| --- | --- | --- |
| 本机摄像头 | 分析电脑上的摄像头或 USB 摄像头 | 摄像头编号，通常是 `0` |
| 这台设备的摄像头 | 手机拍摄，电脑分析 | 不用填；需要 HTTPS（见下文） |
| 视频流或文件 | 网络摄像头 App、RTSP 摄像头，或把录像当作直播回放 | `rtsp://…`、`http://手机IP:8080/video` 或文件路径 |

再选择 **单打** 或 **双打**。双打时每边跟踪两名球员。

### 用手机当摄像头

手机浏览器只允许 HTTPS 页面使用摄像头。用本地证书启动：

```bash
smart-badminton live --library /path/to/matches --host 0.0.0.0 --https
```

在手机上打开打印出的 `https://` 地址。浏览器会提示一次自签名证书，确认信任这个地址即可。选择 **这台设备的摄像头** 后开始。手机每秒向电脑发送约 8 帧画面和麦克风声音。勾选 **同时录像** 时，手机会保存一份带声音的原画质录像，按 **结束** 后上传到素材库的 `Live/` 文件夹，之后可以在 Studio 里做完整分析。

网络摄像头 App（例如提供 `http://手机IP:8080/video` 的应用）不需要 HTTPS，在 **视频流或文件** 中填写它的地址即可。

## 只需校准一次

某个机位第一次使用时，Studio 会显示一帧静止画面。依次点击**单打**边线与底线的四个交点：近左、近右、远右、远左。Studio 会据此推算球场轮廓（单打或双打）、两个半场、球网和羽球飞行空域，之后所有位置都以米为单位计算。摄像头移动后需要重新校准。

如果 Studio 已经有同一机位的校准，点 **使用 Studio 的校准** 即可直接复制。

把摄像头架高，放在一侧底线后方，让整片场地都在画面里，尽量避免广角畸变。

## 实时分析测量什么

- **回合状态和时长。** 回合的开始和结束依据羽球飞行，有声音时还会结合回合模型对击球声的判断。模型需要约 2 秒上下文，所以会稍有延迟；羽球飞行能让计时更早开始。
- **每回合拍数和每位球员的击球数。** 羽球换边，或者挥拍的手腕碰到羽球时计一拍。实时帧率下这是估计值，离线的接触分析更精确。
- **球员跟踪。** 每名球员都有稳定的编号（近场 1、近场 2、远场 1、远场 2），双打搭档交叉跑位或相互遮挡时也不会弄混。跑动距离、当前速度和最高速度都基于校准后的球场米制坐标。
- **挥拍。** 每名球员的快速手腕动作。

## 速度与准确度

在四核笔记本 CPU 上，同时开启姿态和羽球跟踪时，实时分析约为每秒 6–7 帧。NVIDIA GPU 会用半精度运行两个模型，可以跟上摄像头帧率。CPU 上可以用准确度换速度：

- 降低推理尺寸：`--pose-size 384 --shuttle-size 512`（姿态从 640 降到 480 已能减少约 40% 耗时；再小会损失远场细节）；
- 取消勾选 **跟踪羽球**，或用 `--no-shuttle` 启动（这时回合判断依赖回合模型）；
- Intel CPU 上导出 OpenVINO 版姿态模型可能更快：`yolo export model=models/yolo11n-pose.pt format=openvino`，再用 `--pose-model` 传入导出的文件夹。请对照页面上的帧率判断；我们测试时 ONNX 导出并不比 PyTorch 快。

实时页面会显示实际分析帧率。电脑忙不过来时多余的帧会直接丢弃而不是排队，所以画面始终是最新的。
